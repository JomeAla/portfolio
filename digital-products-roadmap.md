## How to Convert to ZIP & Upload

For each product:

1. **Download** the `.html` file from the link above
2. **Open in browser** to verify the content looks good
3. **Rename to zip**: `{slug}.html` → `{slug}.zip` (or create a ZIP with the HTML inside)
4. **Upload via Admin:** Login → Products → Edit product → Upload file → Save
5. **Mark complete** in this doc when done
