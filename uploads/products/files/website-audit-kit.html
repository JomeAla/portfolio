20-Point Website Audit Checklist

1. Technical Performance CRITICAL

1.1 Website Speed Test - Run Google PageSpeed Insights. Target: 90+ on mobile, 95+ on desktop
Tool: pagespeed.web.dev
1.2 Mobile Responsiveness - Test on mobile phone. Elements should stack, not horizontal scroll
Tool: Chrome DevTools → Toggle Device Mode
1.3 HTTPS Security - URL should start with https:// and show lock icon
1.4 Page Weight - Each page should be under 3MB (images optimized)

2. User Experience HIGH

2.1 Navigation Clarity - Can users find every main page in 3 clicks or less?
2.2 Page Load Time - All pages load in under 3 seconds on 3G
2.3 CTA Visibility - Every page has at least one clear call-to-action button
2.4 Contact Accessibility - Phone number and email visible and clickable

3. SEO Optimization HIGH

3.1 Meta Titles - Every page has unique, descriptive title (50-60 chars)
3.2 Meta Descriptions - Every page has unique description (150-160 chars)
3.3 Heading Structure - Single H1 per page, logical H2-H6
3.4 Image Alt Text - All images have descriptive alt text
3.5 Sitemap - XML sitemap exists and submitted to Google Search Console
3.6 Robots.txt - Exists and doesn't block important pages

4. Security CRITICAL

4.1 SSL Certificate - Valid and showing secure lock icon
4.2 Contact Forms - Working and receiving submissions
4.3 Update Status - CMS, plugins, themes are all up to date
4.4 Backups - Automated backups working (weekly minimum)

5. Content HIGH

5.1 About Page - Complete with team/credentials
5.2 Contact Information - Phone, email, address, map (if applicable)
5.3 Terms & Privacy - Legal pages present and accurate
5.4 Last Updated Date - Content shows freshness (no 2020 posts in 2026)

6. Conversion Elements HIGH

6.1 Phone Number - Visible on mobile (tap to call)
6.2 WhatsApp Button - WhatsApp Business integration visible
6.3 Social Links - All social media profiles linked and working
6.4 Testimonials - At least 3 customer testimonials visible
