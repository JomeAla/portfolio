WordPress Starter Kit - Complete Setup Guide

Welcome to the WordPress Starter Kit! This guide will walk you through building a professional WordPress website from scratch in under 30 minutes per page.

Before You Begin: Make sure you have your domain name and hosting ready. If you haven't gotten these yet, see Step 1 below.

1Get Domain & Hosting

If you don't have a domain and hosting yet, follow these recommendations:

Recommended Hosting Providers (Nigeria):

  • 域名.com.ng - Local support, Naira payments
  • SmartWeb - Managed WordPress hosting
  • Whogohost - Affordable shared hosting

International Options:

  • Cloudways - Managed cloud hosting (recommended)
  • SiteGround - Great performance & support
  • Hostinger - Budget-friendly
Pro Tip: Get a .com.ng domain for local businesses or .com for international reach. Most providers offer free domain with annual hosting.

2Install WordPress

Most hosting providers offer one-click WordPress installation:

  1. Log into your hosting account (cPanel or managed dashboard)
  2. Look for "WordPress" or "Install WordPress" option
  3. Enter your site name and create admin credentials
  4. Click Install - typically takes 2-5 minutes
  5. Access your site at yourdomain.com/wp-admin
Important: Save your admin credentials somewhere safe! You'll need them to log in.

3Essential WordPress Settings

General Settings

  1. Go to Settings → General
  2. Set your Site Title and Tagline
  3. Set Timezone to Africa/Lagos
  4. Set Date Format and Time Format

Reading Settings

  1. Go to Settings → Reading
  2. Set "Your homepage displays" to A static page
  3. Select your homepage (we'll create this in Step 6)

Permalink Settings

  1. Go to Settings → Permalinks
  2. Select Post name (e.g., yourdomain.com/sample-post)
  3. Click Save Changes

4Install Recommended Plugins

Go to Plugins → Add New and install these FREE essential plugins:

SEO Plugins (Install One):

  • Yoast SEO - Most popular, great for beginners
  • RankMath - Powerful free version

Page Builder (Choose One):

  • Elementor - Drag & drop, beginner-friendly (RECOMMENDED)
  • Divi - Visual builder with many templates
  • Gutenberg - Built-in block editor

Security:

  • Wordfence - Free firewall & malware scanner
  • Solid Security (formerly iThemes Security)

Performance:

  • WP Super Cache - Free caching plugin
  • Smush - Image optimization

Contact Forms:

  • WPForms - Drag & drop form builder (RECOMMENDED)
  • Contact Form 7 - Simple, lightweight

Analytics:

  • MonsterInsights - Connect Google Analytics easily
Pro Tip: Don't install too many plugins! More plugins = slower site. Only install what you need.

5Choose & Customize Theme

Free Themes (Recommended):

  • Astra - Lightweight, fast, lots of starter templates
  • GeneratePress - Super fast, clean design
  • Hestia - Modern one-page design
  • OceanWP - Feature-rich, good for e-commerce

Premium Themes (Optional):

  • Divi Theme - $89 one-time, unlimited websites
  • Astra Pro - $59/year, more templates
  • Elementor Pro - $99/year, includes theme builder

How to Install:

  1. Go to Appearance → Themes
  2. Click Add New
  3. Search for your chosen theme
  4. Click Install then Activate

Using Starter Templates (with Astra + Elementor):

  1. Install Astra Theme
  2. Install Elementor Page Builder
  3. Go to Appearance → Astra Options → Starter Templates
  4. Browse and import a template that matches your business
  5. Customize with your content

6Create Essential Pages

Every business website needs these core pages:

  1. Homepage - Your main landing page
  2. About Page - Your story, mission, team
  3. Services/Products Page - What you offer
  4. Contact Page - How to reach you
  5. Blog - News, tips, updates

How to Create a Page:

  1. Go to Pages → Add New
  2. Enter page title
  3. Click Edit with Elementor (if using Elementor)
  4. Add your content using drag & drop
  5. Click Publish when done
Pro Tip: Use our included page templates to speed up this process!

7Set Up Navigation

Create Menu:

  1. Go to Appearance → Menus
  2. Enter a menu name (e.g., "Main Menu")
  3. Add pages from the left panel
  4. Drag to reorder
  5. Check Primary Menu at the bottom
  6. Click Save Menu

Add Links to Menu:

  • Pages (created in Step 6)
  • Custom links (e.g., to external sites)
  • Categories (for blog posts)

8Configure SEO

Using Yoast SEO:

  1. Install & activate Yoast SEO
  2. Go through the Setup Wizard (first-time popup)
  3. For each page, fill in:
    • SEO Title (appears in Google)
    • Meta Description (summary in search results)
    • Focus keyword

Important SEO Settings:

  • Create XML Sitemap - Submit to Google Search Console
  • Set up Google Search Console - Track your rankings
  • Install Google Analytics - Track visitors
Don't Skip: Check our SEO Checklist (included in this kit) for complete optimization steps!

9Add Contact Forms

Using WPForms:

  1. Install & activate WPForms
  2. Go to WPForms → Add New
  3. Select Contact Form template
  4. Customize fields as needed
  5. Save your form
  6. Add to any page using the WPForms block

Form Fields to Include:

  • Name (required)
  • Email (required)
  • Phone (optional)
  • Message (required)
  • Consent checkbox (for GDPR)

Email Notifications:

  1. Go to WPForms → Settings → Notifications
  2. Set up email to send to your email when someone submits

10Launch Your Site

Pre-Launch Checklist:

  • Test all pages on mobile
  • Check all links work
  • Verify forms send notifications
  • Test loading speed (use GTmetrix or PageSpeed Insights)
  • Add privacy policy page (required by law)
  • Test contact form submissions

Going Live:

  1. If using staging: Push changes to live
  2. Update nameservers if you changed DNS
  3. Wait 24-48 hours for full propagation
  4. Test your live site
  5. Submit sitemap to Google Search Console
Congratulations! Your WordPress site is now live! Remember to:
  • Update content regularly
  • Backup your site weekly
  • Keep plugins updated
  • Monitor Google Analytics
