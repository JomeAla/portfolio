WordPress SEO Checklist

Complete this checklist before launching your site to maximize your chances of ranking on Google.

Priority Guide: 🔴 High = Do first | 🟡 Medium = Important | 🟢 Low = Nice to have

🔴 Technical SEO

Enable HTTPS (SSL)
Your site must use HTTPS. Most hosts offer free SSL via Let's Encrypt.
Set Up Yoast or RankMath SEO Plugin
Install and configure your SEO plugin. Complete the setup wizard.
Create XML Sitemap
Your SEO plugin automatically creates a sitemap at /sitemap.xml
Submit Sitemap to Google Search Console
Go to search.google.com/search-console, add your site, submit sitemap
Set Preferred Domain (www vs non-www)
In Yoast: SEO → Settings → Content Types → Set your preferred domain
Enable Breadcrumbs
In Yoast: SEO → Settings → Breadcrumbs → Enable
Check Site Speed
Use Google PageSpeed Insights. Target: 90+ on mobile and desktop

🔴 On-Page SEO (Per Page)

Write SEO Title (50-60 characters)
Include your main keyword. Use Yoast's SEO title field.
Write Meta Description (150-160 characters)
Include a call-to-action and keywords. Make it compelling!
Set Focus Keyword
Tell Google what the page is about. Optimize content around it.
Add SEO-Friendly URL Slug
Use: yourdomain.com/primary-keyword (no stop words)
Add Heading Tags (H1, H2, H3)
One H1 per page (page title). Use H2s for main sections.
Add Images with Alt Text
Every image needs descriptive alt text including your keyword.
Optimize Image File Names
Name files like: wordpress-starter-kit-guide.jpg (not IMG_4829.jpg)
Add Internal Links
Link to 2-3 related pages within your content.
Make Content 300+ Words
Google prefers comprehensive content. Aim for 1000+ words for important pages.

🟡 Content SEO

Start a Blog
Publish 2-4 articles per month targeting specific keywords.
Write Long-Form Content
Comprehensive guides (2000+ words) tend to rank better.
Add FAQ Section
Add schema markup for FAQs to get rich snippets in Google.
Update Content Regularly
Refresh old posts with new information. Google prefers fresh content.

🟡 Local SEO (If You Have a Physical Business)

Set Up Google Business Profile
Go to business.google.com and claim your business listing.
Add NAP to Website
Name, Address, Phone number in footer. Use schema markup.
Get Local Backlinks
Get listed in Nigerian directories: VConnect, BusinessList, etc.

🟢 Mobile SEO

Use Responsive Theme
Your theme must work on mobile. Most modern themes are responsive.
Check Mobile Usability in Search Console
Google Search Console → Enhancements → Mobile Usability
Optimize for Core Web Vitals
LCP < 2.5s, FID < 100ms, CLS < 0.1 (check in PageSpeed Insights)

🟢 Security & Indexing

Block Duplicate Content
Use canonical tags. Yoast handles this automatically.
Check robots.txt
Ensure it allows crawling of important pages.
Noindex Tag Check
Ensure important pages are NOT set to noindex.
Install Security Plugin
Use Wordfence or Solid Security for protection.

Quick Reference: Target Keywords

Page Sample Keywords
Homepage [your city] + [service], best [service] in [city]
Services [service] + [city], [service] near me
About [service] + expert, [service] specialist
Contact [city] + [service] + contact, [service] + [area]
Blog How to [something], [topic] guide, [topic] tips
Pro Tip: Use AnswerThePublic.com or Google autocomplete to find what people search for in your niche!

Next Steps After Launch

  1. Create Google Search Console account
  2. Submit your sitemap
  3. Create Google Analytics account
  4. Set up Google Business Profile (if local)
  5. Publish 3-5 blog posts in first month
  6. Build backlinks gradually (guest posts, directories)
